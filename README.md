# Computer Vision Conference Deadlines

A deadline tracker for conferences that publish computer vision work — from domestic venues in
Japan, Taiwan and Korea (MIRU, CVGIP, IPIU) through regional conferences (ICEIC, ITC-CSCC) up to
the CVPR / ICCV / NeurIPS tier.

**Snapshot date: 2026-10-29.** 105 venues tracked (7 A*, 19 A, 21 B, 3 B-, 31 C, 24 Local). Every date was taken from the venue's own
site where one was reachable; where it was not, the source is named in the Notes column. Rows or
cells marked ⚠ are unverified or come from conflicting sources — **always confirm on the official
site before you plan a submission.**

📅 **Interactive calendar: [`index.html`](index.html)** — month grid, live countdowns,
filtering by tier, and `.ics` export for any subset. It holds the same data as the tables
below, embedded in the file, and runs entirely in the browser with no build step or network
access: clone the repo and open it, or download the single file.

## Legend

| Field | Meaning |
|---|---|
| `Tier` | Rough prestige band: `A*` top-tier, `A` strong, `B` / `B-` solid international, `C` regional, `Local` single-country |
| `TBA` | Next cycle not yet announced. The Notes column carries the previous cycle's dates, labelled `est.`, as a planning estimate |
| `AoE` | Anywhere on Earth — the deadline expires when it is still that date anywhere, i.e. UTC-12 |
| ⚠ | Unverified, or official sources disagree. The conflict is described in Notes |
| `D-n` | Days from the snapshot date to the deadline |

## Caveats

- **Dates move.** Conference deadlines are extended often; several rows here already reflect
  an extension. Treat this file as a starting point, not an authority.
- **Timezones are frequently unpublished.** Where a venue states no timezone, the cell says so.
  Assume the earliest plausible interpretation and submit a day early.
- **Domestic venues are not archival.** Many of the Japanese, Taiwanese and Korean entries
  (MIRU, SSII, ViEW, IPIU, KCC, CVGIP, NCS and the like) publish no indexed proceedings and may
  accept only the local language. The Notes column states the submission language and whether
  the proceedings reach IEEE Xplore / Springer / Scopus — check it before counting one as a
  publication. Several explicitly permit concurrent submission to an international venue.
- **Cadence matters.** ECCV and ACCV are even-year biennial; ICCV is odd-year; IPMI, DAS, ICS,
  IEVC and IS3C have irregular or alternating cycles. The Notes column records the cadence
  where it is not annual.
- **Look-alike conferences exist.** Predatory organisers sell events with names copied from
  real venues (noted inline for ICIAR and ICIAP). Check that the URL matches the series' own
  history and that proceedings appear in IEEE Xplore / Springer / ACM DL. Note also that
  `cvgip.net` is an unrelated SPIE conference in Suzhou, China — not Taiwan's CVGIP.
